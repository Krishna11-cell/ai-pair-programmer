# Contributing to CodeCritiq

We love contributions! Here's how you can help make this project better.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/ai-pair-programmer.git`
3. Create a feature branch: `git checkout -b feature/amazing-feature`
4. Install dependencies: `npm install`
5. Compile: `npm run compile`

## Development Workflow

1. Run `npm run watch` for auto-compilation on file changes
2. Press `F5` in VS Code to launch an Extension Development Host
3. Make changes and test in the development host
4. Run `npm run lint` to check for code style issues
5. Run `npm test` to run the test suite

## Code Style

- Follow the existing TypeScript conventions
- Use `const` and `let` instead of `var`
- Use strict equality (`===` / `!==`)
- Keep functions focused and under 30 lines where possible
- Add appropriate type annotations

## Pull Request Guidelines

- Keep PRs focused — one feature or fix per PR
- Write clear commit messages
- Update documentation if needed
- Add tests for new functionality
- Ensure all tests pass and lint is clean

## Reporting Issues

- Use the [issue tracker](https://github.com/Krishna11-cell/ai-pair-programmer/issues)
- Include steps to reproduce, expected behavior, and actual behavior
- Include VS Code version and extension version
- Attach screenshots if applicable

## Feature Requests

- Open an issue with the "enhancement" label
- Describe the feature and use case
- Explain why it would be valuable to other users

Thank you for contributing!
